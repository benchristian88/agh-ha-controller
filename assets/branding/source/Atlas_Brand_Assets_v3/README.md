# Atlas Brand Asset Pack — V3

This pack contains the refined Atlas symbol requested after the third review.

## What changed in V3

- A deliberate **42-unit optical gap** now separates each end of the blue arc from the outside edge of the A.
- The primary arc terminals remain **angled parallel to the A legs**, so the geometry feels related without touching.
- A fully rounded-terminal alternative is included in `ALTERNATE_ROUNDED_GAP`.
- The foundation bar is centred, narrowed and aligned inside the A opening.
- Every mark, Homarr/dashboard asset, app icon and favicon is centred using the **actual visible artwork bounds**, not the original design canvas.
- All artwork uses flat colour only: no gradients, shadows or effects.

## Brand colours

- Atlas Blue: `#2563EB`
- Atlas Teal: `#0EA5A3`
- Atlas Charcoal: `#111111`
- White: `#FFFFFF`

## Recommended files

- Homarr or dashboard on a light tile: `SVG/PRIMARY_ANGLED_GAP/atlas-mark-color-light.svg`
- Homarr or dashboard on a dark tile: `SVG/PRIMARY_ANGLED_GAP/atlas-mark-color-dark.svg`
- Website on white: `atlas-mark-color-light.svg`
- Dark application UI: `atlas-mark-color-dark.svg`
- Monochrome print or embossing: `atlas-mark-black.svg` or `atlas-mark-white.svg`
- iOS / app icon on dark: `PNG/APP_ICONS/atlas-app-icon-dark-1024.png`
- iOS / app icon on light: `PNG/APP_ICONS/atlas-app-icon-light-1024.png`
- Browser favicon: `WEB/favicon.ico` and `WEB/favicon.svg`
- Apple touch icon: `WEB/apple-touch-icon.png`
- Android / PWA: `WEB/android-chrome-192x192.png`, `WEB/android-chrome-512x512.png`, and `WEB/site.webmanifest`

## App icon note

The production app-icon PNGs are intentionally square and opaque. Do not add rounded corners to the source artwork; iOS, iPadOS, macOS and most Android launchers apply their own masks.

## Clear space

Keep clear space around the mark equal to at least half the thickness of the blue arc. Avoid placing text or other marks inside this area.

## File formats

- SVG: editable vector artwork
- PNG: transparent marks plus opaque app icons at common sizes
- ICO: multi-resolution browser favicons
- WEB: ready-to-drop website/PWA files

No trademark or name-availability clearance is included in this design pack.
